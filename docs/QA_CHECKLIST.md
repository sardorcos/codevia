# Ручная проверка на iPhone (перед внешним TestFlight и ревью)

Автотесты гоняют Chromium и WebKit на десктопе. Эти сценарии проверяются только на реальном устройстве. Минимум: маленький экран (iPhone SE / 13 mini) и большой (Pro Max), iOS 16.4 и последняя iOS.

## Запуск и хранение
- [ ] Первый запуск: приветствие → «Начать с примеров» → 3 проекта.
- [ ] Правка файла → свернуть приложение сразу (≤1 с) → выгрузить из памяти → открыть: правка на месте.
- [ ] «Файлы» → На iPhone → Codevia Pocket: папки проектов видны, файлы открываются.
- [ ] Переименование проекта меняет имя папки в «Файлах».
- [ ] Режим полёта: всё работает (редактор, предпросмотр, Python, PHP).

## Редактор и клавиатура
- [ ] Клавиатура не перекрывает строку ввода и панель символов; нижняя навигация прячется, пока клавиатура открыта.
- [ ] Нажатие на панель символов не закрывает клавиатуру; «( )» ставит курсор внутрь.
- [ ] Отмена и повтор, поиск и замена, долгое нажатие для выделения, копирование и вставка.
- [ ] Внешняя клавиатура: ⌘S сохраняет, ⌘↩ запускает, ⌘Z отменяет.
- [ ] Поворот экрана в альбомную ориентацию: учтены безопасные зоны (чёлка или Dynamic Island).

## Предпросмотр
- [ ] Пример сайта: стили, логотип, кнопка (fetch JSON), консоль, переход на «О нас».
- [ ] Полноэкранный режим: кнопка выхода видна под Dynamic Island.
- [ ] Включить «Интернет в предпросмотре» → страница с Bootstrap через CDN.

## Python / PHP
- [ ] Первый запуск Python (загрузка ≈2–5 с), вывод, input() с полем «Ввод».
- [ ] `while True: pass` → «Стоп» → следующий запуск работает.
- [ ] PHP: страница, ссылка с ?name=, ошибка PHP видна в консоли.
- [ ] Python → PHP → Python подряд, затем 10 минут простоя: приложение не падает и не перезагружается.

## Импорт / экспорт
- [ ] Импорт ZIP из «Файлов», из Почты (через «Сохранить в Файлы»), архив с кириллицей из Windows.
- [ ] Экспорт ZIP → системное меню «Поделиться» → «Сохранить в Файлы» и AirDrop.
- [ ] Резервная копия всех проектов → импорт → проекты восстановлены.

## Доступность
- [ ] VoiceOver: все кнопки озвучиваются, по листам можно перемещаться, «Закрыть» доступна.
- [ ] Крупный шрифт (Настройки → Универсальный доступ → Крупный текст): интерфейс читается, ничего не обрезано критично.
- [ ] Уменьшение движения: анимации листов отключены.
