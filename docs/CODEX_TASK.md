# Задание Codex: интеграция Codevia Compact UI 0.3

Работай в **текущем существующем репозитории Codevia Pocket 0.2**, не создавай новый проект. В соседней папке находится автономный пакет `codevia_ui_0_3` с прототипом (`index.html`, `src/styles.css`, `src/app.js`) и примерами экранов.

Задача: перенеси **только дизайн-систему и пользовательские паттерны**, не заменяя текущую бизнес-логику. Должны остаться работоспособны CodeMirror 6, IndexedDB, ZIP, Pyodide, PHP.wasm, Codevia Connection Bridge, FTP, FTPS, SSH, SFTP, тесты и iOS Capacitor.

## План

1. Проведи аудит текущего layout: Header, Sidebar, Tabs, Buttons, File list, Editor controls, Runtime, Servers, Modals. Сохрани рабочую функциональность.
2. Создай ветку `feature/compact-ui-0.3` и новые стили/компоненты с дизайн-токенами в `docs/INTEGRATION.md`.
3. Главная: действия «Новый», «Импорт», «Серверы» в одной строке; последний проект; компактный список всех проектов. Убери повторяющиеся hero-блоки и вводные секции.
4. Рабочая навигация на iPhone: ровно четыре вкладки «Файлы», «Код», «Просмотр», «Запуск». История и Проверка в действиях верхней панели.
5. Код: максимум свободной площади, вкладки файлов на 44px, keybar 34px, autosave/dirty, настройка размера шрифта и переноса, качественное отображение клавиатуры.
6. Создай единые кнопки: primary cyan, secondary graphite, ghost, destructive; обеспечь touch targets ≥44pt и VoiceOver labels. Убери большие повторные CTA.
7. Серверы: компактный список подключений, отдельно SFTP/SSH/FTPS/FTP, статус реального подключения через Bridge, no false-positive states. Никогда не сохраняй пароль в localStorage или IndexedDB.
8. Python/PHP: визуально компактная панель «Выполнение», консоль, индикатор загрузки, остановка, ошибки; не удаляй существующие движки.
9. Проверь состояние при offline, runtime error, bridge offline, modified remote file, ZIP conflict, no storage, iPhone keyboard.
10. Запусти существующие тесты и дополнительные regression/E2E. Сделай screenshot review 390×844 и 1024×768. Не публикуй до прохождения тестов. Предоставь diff и список изменённых файлов.

## Критерии приёмки

- Действующее сохранение и откат локальных проектов без миграции данных.
- Python и PHP выполняют существующие образцы без изменения результата.
- SFTP/SSH/FTPS/FTP проходят test-server regression, безопасное сравнение и откат работают.
- Интерфейс не имеет горизонтальной прокрутки всего экрана при 375–430px.
- Кнопки и фокус не перекрываются экранной клавиатурой iOS.
- Нет fake success states для Server Connect, Deploy и Save.

Ни один технический модуль из `src/app.js` демоверсии не заменяет production-реализацию основного приложения. Он служит примером UX.
