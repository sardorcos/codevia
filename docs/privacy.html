Политика конфиденциальности Codevia Pocket

Дата вступления в силу: 25 ноября 2026 г. (версия 1.1)

Мы не собираем данные

Codevia Pocket не собирает, не хранит на серверах, не передаёт и не продаёт персональные данные. В приложении нет аналитики, рекламы, трекинга и учётных записей Codevia. У разработчика нет серверов, на которые попадали бы ваши данные.

Ваши файлы

Проекты, история версий и настройки хранятся только на вашем устройстве — в папке приложения, которую видно в приложении «Файлы». Они могут попасть в резервную копию iCloud или компьютера, если вы включили её в настройках iOS. Разработчик не имеет к ним доступа.

Выполнение кода

Python, JavaScript/TypeScript и PHP выполняются локально, внутри приложения. Код не отправляется на внешние серверы для выполнения.

Сеть — только по вашему действию

Приложение работает без подключения к интернету. Сетевые запросы происходят только когда вы сами используете одну из функций:

  • Пакеты Python. Если ваш код импортирует пакет, которого нет в приложении, он загружается с CDN проекта Pyodide (cdn.jsdelivr.net) или из PyPI (pypi.org, files.pythonhosted.org) и сохраняется на устройстве. Это можно отключить: «Настройки → Загружать пакеты Python».
  • HTTP-клиент. Запросы, которые вы составляете и отправляете, уходят напрямую на указанный вами адрес.
  • GitHub. Если вы подключите свой аккаунт GitHub, токен доступа хранится в Связке ключей iOS только на этом устройстве и отправляется только на github.com. Код проекта отправляется в ваш репозиторий только когда вы сами нажимаете «Отправить», «Создать репозиторий» или «Опубликовать сайт». Обработку данных на GitHub регулирует политика GitHub. Отключить доступ можно в приложении и на github.com.
  • Предпросмотр. Если вы включите «Разрешить интернет в предпросмотре», страницы ваших проектов смогут загружать ресурсы с внешних сайтов (шрифты, библиотеки с CDN). Эти запросы инициирует ваш код.

Камера и фотографии

Камера и медиатека открываются только когда вы сами выбираете фото, чтобы добавить его в проект или взять с него цвет пипеткой. Изображения остаются на устройстве.

Передача файлов

Файлы покидают устройство только тогда, когда вы сами экспортируете их, отправляете через системное меню «Поделиться» или в свой репозиторий GitHub.

Журнал ошибок

При сбоях приложение записывает технический журнал только на устройстве. Он передаётся разработчику, только если вы сами отправите его через «Настройки → Журнал ошибок → Поделиться».

Дети

Приложение не собирает данные ни от кого, в том числе от детей.

Изменения и контакты

Если политика изменится, новая версия будет опубликована на этой странице. Вопросы можно задать на странице поддержки.

Codevia Pocket Privacy Policy

Effective date: November 25, 2026 (version 1.1)

We do not collect data

Codevia Pocket does not collect, store on servers, share or sell personal data. There is no analytics, advertising, tracking or Codevia account. The developer runs no servers that your data could reach.

Your files

Projects, version history and settings are stored only on your device, in the app's folder visible in the Files app. They may be included in your iCloud or computer backup if you enabled it in iOS settings. The developer has no access to them.

Running code

Python, JavaScript/TypeScript and PHP run locally inside the app. Code is never sent to external servers to be executed.

Network — only when you act

The app works offline. Network requests happen only when you use one of these features yourself:

  • Python packages. If your code imports a package that is not built into the app, it is downloaded from the Pyodide CDN (cdn.jsdelivr.net) or PyPI (pypi.org, files.pythonhosted.org) and kept on the device. You can turn this off in Settings → Download Python packages.
  • HTTP client. Requests you compose and send go directly to the address you enter.
  • GitHub. If you connect your GitHub account, the access token is stored in the iOS Keychain on this device only and is sent only to github.com. Project code goes to your repository only when you tap Push, Create repository or Publish site. GitHub's handling of data is governed by the GitHub Privacy Statement. You can disconnect in the app and on github.com.
  • Preview. If you turn on “Allow internet in preview”, your project's pages may load resources from other websites (fonts, CDN libraries). These requests are made by your code.

Camera and photos

The camera and photo library open only when you choose a photo to add to a project or to pick a colour from it. Images stay on your device.

Sharing files

Files leave your device only when you export them, share them through the system Share sheet, or push them to your own GitHub repository.

Error log

When something fails, the app writes a technical log on the device only. It reaches the developer only if you send it yourself via Settings → Error log → Share.

Children

The app collects no data from anyone, including children.

Changes and contact

If this policy changes, the new version will be published on this page. Questions: see the support page.
