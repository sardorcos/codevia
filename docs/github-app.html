GitHub App для Codevia Pocket

Эта страница создаёт GitHub App, через который приложение входит в GitHub по коду (Device Flow). Все поля и права уже заполнены — на GitHub останется нажать одну кнопку.

Что получит приложение
  • Содержимое репозиториев — чтение и запись (клонирование, коммит, пуш)
  • GitHub Pages — чтение и запись (публикация сайта)
  • Администрирование — чтение и запись (кнопка «Создать репозиторий»)
  • Метаданные — только чтение (обязательно для любого GitHub App)

Доступ появляется только к тем репозиториям, на которые пользователь сам установит приложение. Вебхуков нет.

Откроется github.com под вашим аккаунтом. Проверьте имя и нажмите Create GitHub App. Если имя занято, поменяйте его на «Codevia Pocket App».

Публичная страница:

Осталось два переключателя

  1. Откройте настройки приложения.
  2. Поставьте галочку Enable Device Flow.
  3. Снимите галочку Expire user authorization tokens.
  4. Нажмите Save changes внизу страницы.

Затем пришлите Client ID в чат с Claude — это публичное значение, его можно писать открыто. Client secret и private key не создавайте: приложению они не нужны.

Секреты, которые GitHub выдаёт при создании, эта страница не показывает и никуда не отправляет.

Почти готово

  1. Откройте github.com/settings/apps и выберите созданное приложение.
  2. Скопируйте Client ID (начинается с Iv).
  3. Поставьте галочку Enable Device Flow, снимите Expire user authorization tokens, нажмите Save changes.
  4. Пришлите Client ID в чат с Claude.
