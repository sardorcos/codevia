Политика конфиденциальности

ModelLink · обновлено 26 ноября 2026

ModelLink не собирает данные. В приложении нет регистрации, рекламы, аналитики и отслеживания.

Где хранятся файлы

Проекты, файлы, версии, замечания и голосовые записи хранятся только на вашем устройстве. Приложение не отправляет их на серверы. Файл покидает устройство, только когда вы сами отправляете его через меню «Поделиться».

Разрешения

  • Face ID / код-пароль — только чтобы открыть сейф в приложении.
  • Камера — только чтобы отсканировать QR-код ключа защищённого пакета.
  • Микрофон — только для голосовых замечаний; записи хранятся на устройстве.

Сеть

Приложение работает офлайн. Единственный необязательный запрос — проверка списка отзыва защищённого пакета по адресу, который указал отправитель. Режим «Без следов» отключает и его.

Удаление данных

Удалить данные можно в «Настройки → Удалить все данные» или удалив приложение.

Privacy Policy

ModelLink · updated November 26, 2026

ModelLink does not collect any data. There is no sign-up, advertising, analytics or tracking.

Where files are stored

Projects, files, versions, remarks and voice recordings are stored only on your device and are never sent to servers. A file leaves the device only when you share it yourself.

Permissions

  • Face ID / passcode — only to unlock the in-app vault.
  • Camera — only to scan the QR key of a protected package.
  • Microphone — only for voice remarks, kept on the device.

Network

The app works offline. The only optional request is a revocation-list check for a protected package at an address set by its sender; “No trace” mode disables it.

Deleting data

Use Settings → Delete all data, or delete the app.
