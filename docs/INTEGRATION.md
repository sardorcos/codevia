# Применение Compact UI к Codevia Pocket 0.2 (React + TypeScript)

## Цель

Сменить оболочку на UI 0.3, **не переписывая** существующие слои: IndexedDB-хранилище исходного проекта, ZIP-импорт, CodeMirror 6, Pyodide/PHP.wasm runtime, API Codevia Connection Bridge, SFTP/SSH/FTP, логи, историю версий и экспорт.

## Что нужно получить из исходного проекта

- исходные компоненты layout, sidebar, topbar, buttons и page routes;
- пути/названия существующих функций импорта, запуска Python/PHP и вызовов Bridge;
- `package.json`, тесты, конфигурацию iOS Capacitor;
- актуальные дизайн-токены, чтобы снять дублирование.

Эти файлы недоступны в данном сеансе. Поэтому не следует механически заменять существующий `App.tsx` автономной демонстрацией.

## Рекомендуемая целевая структура

## Контракт экранов

| Экран | Компоновка | Чего не менять |
|---|---|---|
| Главная | Заголовок 24px; Новый / Импорт / Серверы; последняя работа + один список | IDs проектов и хранилище |
| Файлы | Поиск 34–40px, фильтры, строки 48–52px | Структура, бинарные данные, права |
| Код | Строка вкладок 44px, код занимает остаток, keybar 34px | CodeMirror 6, undo/redo, файл-URI |
| Предпросмотр | Управление 42px, iframe растягивается на высоту | Изоляция предпросмотра, CSP |
| Запуск | Одна кнопка Запустить, консоль, остановка | Web Workers, Pyodide, PHP.wasm, лимиты |
| Серверы | Протоколы, профили, состояние, журнал | Bridge API, host-key/cert checks, secrets |
| Изменения | Плоский diff и точки восстановления | Алгоритм версионирования |

## Дизайн-токены и правила кнопок

- `--bg: #0C0E12`, `--surface: #14171C`, `--panel: #191D24`.
- `--text: #F2F4F7`, `--muted: #929BA9`, `--accent: #40C8F6`.
- Основная кнопка: заливка cyan, тёмный текст, высота визуально 40–42px, интерактивная зона не менее 44px на iOS.
- Вторичная: нейтральная поверхность, тонкая рамка; ghost: без рамки.
- Иконка: визуально 20px, интерактивная зона 44px.
- Скругление кнопки 10–11px, панели 12–15px; не использовать двойные рамки.
- Основной контейнер мобильного экрана: `min-height: 0; display: flex; overflow: hidden`.
- Нижняя навигация: ровно четыре действия в рабочем пространстве (`Файлы`, `Код`, `Просмотр`, `Запуск`). История и Проверка в верхних действиях.
- Сохранять safe-area через `env(safe-area-inset-bottom)`.

## Обязательная интеграционная работа

1. Создать **новую ветку** в исходном репозитории Codevia 0.2.
2. Вынести компоненты кнопок в `ui/`, заменить разрозненные стили классов.
3. Подключить компактный layout к текущим роутам, сохранив существующую маршрутизацию.
4. **Не подменять CodeMirror** автономным textarea из превью: текущий редактор технически сильнее и должен остаться.
5. Оставить Pyodide/PHP.wasm и Bridge без изменений. Перенести только разметку состояния запуска и панели сервера.
6. Проверить клавиатуру iOS, long-press selection, orientation, VoiceOver, динамический шрифт.
7. Проверить ZIP import/export, контрольные точки и архивы пользователей без миграции/удаления данных.
8. Проверить SFTP/FTP/FTPS и SSH на тестовом сервере, включая конфликт публикации и откат.
9. Сравнить screenshots 390×844 и 1024×768 с эталонным дизайном и зафиксировать расхождения.
10. После полноценной регрессии публиковать отдельную сборку; не заменять основную версию одной HTML-демонстрацией.

## Проверочные сценарии перед публикацией

- `HTML → CSS change → Preview → Export ZIP → Reimport`, затем сравнение байтов файлов.
- `Python → Run → Stop`, `PHP → Run → Page`, проверка логов ошибок.
- `Server → SFTP → Open → Edit draft → Preview diff → Confirm publish → Rollback`.
- `SFTP changed externally → publish blocked with conflict`.
- `Bridge offline → clear error; local files remain accessible`.
- Работа офлайн без сервера на любом экране локальных файлов.
- Клавиатура не перекрывает code input, терминал или кнопку сохранения.

## Граница этой поставки

`src/app.js` демонстрирует UX и содержит отдельное мини-хранилище, ZIP и просмотр. Этот код полезен как поведенческий прототип, но его нельзя незаметно объявить production-обновлением `codevia-pocket.sardor-cos.chatgpt.site`.
