Codevia Pocket — поддержка

Редактор кода для iPhone: сайты (HTML, CSS, JavaScript), Python 3 и PHP 8.3 работают прямо на устройстве.

Связаться с нами

Сообщить об ошибке или предложить улучшение: создать обращение. Мы отвечаем в течение нескольких рабочих дней.

Частые вопросы

Где хранятся мои проекты? Только на iPhone: приложение «Файлы» → «На iPhone» → Codevia Pocket. Резервную копию всех проектов можно сделать в Настройках приложения.

Нужен ли интернет? Нет. Python и PHP выполняются локально. Интернет понадобится, только если ваша страница загружает ресурсы с CDN — это включается в Настройках.

Можно ли установить пакеты Python (numpy и т. п.)? Пока доступны стандартная библиотека и модули вашего проекта.

Как перенести проект на компьютер? Меню проекта → «Экспорт ZIP» → «Сохранить в Файлы» или AirDrop.
