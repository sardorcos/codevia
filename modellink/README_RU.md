# ModelLink 0.4.0 — интерфейс для мобильных устройств и iOS

**Статус: iOS-приложение (Capacitor 8) со своим нативным модулем файлов. Сборка и загрузка в TestFlight — через Codemagic, workflow `modellink-testflight` в корневом `codemagic.yaml`.**

- Bundle ID: `com.neverlandplayworks.modellink`, приложение «ModelLink» в App Store Connect (SKU `modellink-ios`).
- Хранилище: IndexedDB `modellink-mobile-v04` внутри приложения; формат пакетов `.mlink` версии 1.
- DWG (R13–2018+) и DXF читаются библиотекой acad-ts (MIT, порт ACadSharp) в фоновом потоке; STEP/IFC хранятся и передаются как оригиналы.

## 0.8.0 — полнее DWG, полный экран, 9 языков, аудит интерфейса, страница App Store

- **DWG**: мультивыноски (MLEADER), таблицы (ACAD_TABLE), мультилинии, выноски, сетки (Mesh, PolyfaceMesh), допуски, рамки растровых и PDF-подложек, XLINE/RAY; исправлено положение MTEXT по точке вставки. Неотображаемые типы (3D-тела ACIS и т. п.) перечисляются в строке под чертежом.
- **DWG, блоки и штриховка**: ссылки на блоки (INSERT, MINSERT, таблицы) разворачиваются собственной матрицей преобразования вместо `Insert.explode()` библиотеки — один «трудный» объект больше не скрывает весь блок; содержимое слоя 0 и цвет ByBlock наследуют слой и цвет ссылки. Штриховка по образцу рисуется линиями (`Hatch.explodePattern()`, с ограничением по числу линий, иначе — лёгкая заливка). Точки Defpoints и опорные точки размеров не рисуются. Цвет из форматирования MTEXT (`\C`, `\c`). На тёмном фоне чёрные и тёмно-серые линии осветляются. Ошибки чтения объектов показываются в строке под чертежом.
- **Просмотр**: «На весь экран» для чертежей, 3D, изображений, PDF и текста (плавающая панель: выход, масштаб, вписать, слои, фон); кнопка «Тёмный фон / Светлый фон» с явным состоянием; подсказка жестов скрывается сама; имя файла в две строки.
- Аудиофайлы (MP3, M4A, WAV…) открываются во встроенном проигрывателе.
- **9 языков интерфейса**: русский, английский, узбекский, казахский, турецкий, немецкий, испанский, французский, китайский (упрощённый). `core/i18n.js`, таблица `i18n/strings.tsv` (столбцы ru en uz kk tr de es fr zh; пустая ячейка = английский) → `node scripts/i18n.mjs`. Перевод отрисованного интерфейса на лету; пользовательские данные не переводятся. Числа со словами — `plural(n, key)` с правильными формами (1 замечание / 3 файла / 11 файлов; 1 file / 2 files). Системные запросы iOS — `InfoPlist.strings` для всех 9 языков (`zh-Hans.lproj`).
- **Аудит интерфейса** — `docs/AUDIT_RU.md`: что найдено и что исправлено.
- Голосовые замечания убраны (приложение не запрашивает микрофон).
- **Страница App Store** — `appstore/metadata.json` (ru, en-US, de-DE, fr-FR, es-ES, tr, zh-Hans), скриншоты iPhone 6.9" и iPad 13" в `appstore/screenshots`, тексты TestFlight в `appstore/testflight.json`. Workflow `modellink-app-store-metadata` (без отправки на ревью). Политика конфиденциальности и поддержка — `docs/modellink/` (GitHub Pages из `main`).

## 0.7.0 — безопасная передача и сейф

| Функция | Как устроено |
|---|---|
| **Защищённый `.mlink` v2** | `core/secure.js`. Открытый заголовок (`envelope.json`: отправитель, получатель, срок, «только просмотр», «одноразовый», адрес проверки отзыва) — дополнительные данные AES-256-GCM: подмена любого поля ломает расшифровку. Ключ — PBKDF2-SHA256 (310 000 итераций) от пароля или случайный 256-битный ключ (QR / код `mlink:key:…`). |
| **Только просмотр** | Получатель крутит 3D, включает слои, измеряет, оставляет замечания; экспорт, «Поделиться», Quick Look и выгрузка оригинала скрыты и заблокированы. |
| **Срок действия** | Проверяется при каждом открытии и во время просмотра; перевод часов назад распознаётся. |
| **Одноразовый просмотр** | Пакет открывается один раз на устройстве (отметка хранится отдельно от пакета) и стирается при закрытии, панике или сворачивании. |
| **Отзыв по метке** | Пакет хранит адрес списка отзыва (JSON `{"revoked":[…]}` на любом https-сайте). Проверка — нативный запрос при открытии, если есть сеть и выключен «Без следов»; без сети действует срок. «Отправленные пакеты» → «Отозвать» → выгрузить `revocations.json`. |
| **Песочница** | Полученный пакет хранится только в зашифрованном виде, расшифровывается в память; не попадает в «Мои файлы», недавние, поиск. Замечания получателя — внутри пакета. |
| **Именной водяной знак** | Имя/компания получателя, дата и ID пакета поверх каждого файла пакета. |
| **Снимки и запись экрана** | iOS-события: снимок записывается в журнал пакета, при записи/трансляции экрана содержимое скрывается. Шторка в переключателе приложений. |
| **«Чёрный ящик»** | Журнал событий (создан → открыт → замечание → снимок → ознакомлен → закрыт) — цепочка SHA-256: изменить запись незаметно нельзя. |
| **Ознакомлен с ревизией** | Квитанция `.mlinkack` подписана HMAC-SHA256 ключом пакета и несёт журнал; отправитель импортирует её и видит «Подпись верна». |
| **QR-рукопожатие** | Ключ или пароль показывается QR-кодом, второй телефон сканирует его камерой (AVFoundation) — без пересылки паролей в мессенджерах. |
| **Сейф** | Face ID / код-пароль (LocalAuthentication); файлы проектов в сейфе зашифрованы AES-256-GCM ключом из Связки ключей «только это устройство» — в резервной копии их не прочитать. Закрывается при сворачивании. |
| **Режим паники** | Три пальца на экране, двойной Esc (Mac) или телефон экраном вниз (CoreMotion) — закрыть пакет, запереть сейф, уйти на главный экран. |
| **Без следов** | CSP запрещает веб-части любые сетевые запросы; переключатель отключает и нативную проверку отзыва; в шапке — «100% офлайн». |
| **Отпечатки SHA-256** | Считаются для каждого файла и версии, видны в меню файла, входят в пакет и квитанцию; «Сверить файл» находит ревизию по содержимому. |
| **Обезличивание** | Инструмент «Скрыть» на чертеже или изображении: объекты внутри областей удаляются из экспорта (DXF/SVG/PDF/PNG) и из защищённого пакета — вместо оригинала уходит обезличенная копия. |
| **Экстренная очистка** | Удаляет полученные пакеты, временные и промежуточные файлы, кэш просмотра. |

**Границы защиты.** Шифрование защищает пакет при передаче и хранении. Ограничения на устройстве получателя («только просмотр», срок, одноразовость) — сдерживающие меры: приложение их соблюдает, но человек с ключом может сфотографировать экран другим устройством — для этого и нужен именной водяной знак. Отзыв работает только при опубликованном списке и сети у получателя.

**iPad и Mac.** Приложение универсальное (iPhone + iPad, `TARGETED_DEVICE_FAMILY = 1,2`), на iPad — боковое меню и все ориентации. На Mac с Apple Silicon ставится как iPad-приложение из TestFlight / Mac App Store (в App Store Connect → Pricing and Availability оставить включённым «iPad apps on Mac»); мышь, колесо (масштаб) и Esc работают.

## Любой файл: открыть, посмотреть, экспортировать, поделиться

- **Открыть:** «Открыть файл» (системный выбор файлов), «Поделиться → ModelLink» / «Открыть в ModelLink» из любого приложения — для файлов любого типа.
- **Посмотреть:** встроенные просмотрщики (PDF, изображения, SVG, DXF, STL/OBJ/GLB, текст и код); всё остальное, что умеет iOS (Office, iWork, USDZ с AR, аудио, видео, HEIC…), — кнопкой «Открыть» в Quick Look.
- **Экспорт** (кнопка в просмотре или карточка «Экспорт» на главной):

  | Исходник | Форматы | Где выполняется |
  |---|---|---|
  | DWG | DXF, PDF, SVG, PNG, JPEG | `core/cad.js` (acad-ts) + canvas |
| DXF | PDF, SVG, PNG, JPEG | `core/cad.js` + canvas |
  | STL, OBJ, GLB | USDZ (AR Quick Look), STL, OBJ, GLB, PLY, PNG-снимок вида | `core/convert.js` |
  | Изображения | PNG, JPEG, PDF | canvas; HEIC/TIFF — `ModelLinkConverter.swift` |
  | PDF | PNG / JPEG постранично (до 100 страниц) | PDFKit |
  | Текст, код, CSV, HTML, RTF | PDF (A4) | UIKit printing |
  | Любой файл | ZIP | JSZip |

- **Поделиться:** результат уходит в системное меню (AirDrop, «Сохранить в Файлы», почта, мессенджеры) или сохраняется в проект как новый файл. Страницы PDF отправляются одним набором.

## Главное изменение интерфейса

На первом экране сразу видны все 6 основных действий: **Чертежи, 3D-модели, Измерения, Замечания, Версии, Поделиться**, а также основная кнопка **«Открыть файл»**. Навигация сокращена до 4 вкладок: Главная, Проекты, Замечания, Настройки. В режиме просмотра поля чертежа верхний брендовый заголовок и нижняя навигация скрыты, доступна кнопка «Проект».

## Реально работающие функции этой сборки

- Создание/удаление проектов; автопроект «Мои файлы» при первом импорте; демонстрационный проект.
- Хранение пользовательских исходников на устройстве через IndexedDB, без отправки на сервер.
- Повторное добавление одноимённого файла в тот же проект → новая версия, прежние версии остаются доступны.
- Отображение: PDF (встроенный компонент браузера), SVG и обычные изображения, **DXF (базовая 2D-геометрия)**, **STL, OBJ, GLB (облегчённые 3D-сетки)**.
- Измерения: две точки на DXF в **единицах исходного чертежа** и на изображении в **пикселях**; калибровка изображений и высокоточные промышленные измерения не реализованы.
- Замечания: позиции для DXF и изображений; для 3D отметка привязана к экранному ракурсу, не к инженерной поверхности; для PDF комментарий к текущему файлу без точной привязки к странице.
- Список замечаний, статус «Открыто»/«Выполнено».
- Экспорт пакета `.mlink` (ZIP с JSON-манифестом и всеми версиями файлов), импорт `.mlink` такого же формата, передачa исходников через iOS Share Sheet / Web Share API либо скачивание.
- Файлы всех расширений можно сохранять и передавать в пределах лимита 100 МиБ на файл. **DWG/STEP/IFC в этой автономной сборке пока не визуализируются.**
- Офлайн-кеш оболочки через service worker при установке на HTTPS; сам контент хранится локально в IndexedDB.

## Как запустить

### В браузере с компьютера

```bash
node --version        # 22+
npm start             # http://127.0.0.1:4173
npm test
npm run build         # готовая веб-оболочка в www/
```

Команда `npm start` использует только стандартный Node.js, установка сторонних пакетов для веб-версии не нужна. Исходники `JSZip 3.10.1` включены в `vendor/` вместе с лицензией MIT. В одной отдельной папке есть файл `ModelLink-0.4.0-preview.html` с самостоятельно собранной веб-версией, однако для стабильного IndexedDB на iOS рекомендуется запуск с HTTPS или через Capacitor.

### iOS

Xcode-проект лежит в `ios/App` (Capacitor 8, Swift Package Manager, iOS 16+, только iPhone).

```bash
npm ci
npm run ios:sync          # сборка www/ и копирование в ios/App/App/public
open ios/App/App.xcodeproj
```

Нативная часть (`ios/App/App/`):

- `ModelLinkNativePlugin.swift` — плагин `ModelLinkNative`: системный выбор файлов («Файлы», iCloud Drive), чтение файлов в JS порциями с проверкой SHA-256, экспорт через Share Sheet (AirDrop, «Сохранить в Файлы», почта), Quick Look для PDF, изображений, USDZ (AR) и офисных форматов.
- `ModelLinkImportStore.swift` / `ModelLinkExportStore.swift` — промежуточные папки импорта и экспорта внутри контейнера приложения.
- `SceneDelegate.swift` — принимает файлы, открытые в ModelLink из других приложений («Поделиться → ModelLink», AirDrop, «Файлы»). Типы документов и UTI объявлены в `Info.plist`, пакет `.mlink` экспортируется как собственный тип приложения.
- Share Extension и App Group из пакета 0.3.0 заменены на «Открыть в ModelLink»: тот же сценарий без второй цели подписи.

Веб-слой обращается к модулю через `registerPlugin('ModelLinkNative')` (`vendor/capacitor-core.js`); в браузере используются обычные `<input type=file>`, Web Share API и скачивание.

### TestFlight

Codemagic → приложение `codevia` → workflow **ModelLink → TestFlight** (`modellink-testflight`), ветка с папкой `modellink/`. Workflow:

1. регистрирует bundle ID и проверяет запись приложения в App Store Connect (`tools/asc_setup.py`);
2. запускает тесты, собирает веб-часть, `cap sync ios`;
3. ставит номер сборки из `BUILD_NUMBER`, создаёт или скачивает профиль App Store, подписывает IPA командным сертификатом;
4. загружает сборку в App Store Connect. Через 5–30 минут она появляется в TestFlight для внутренних тестировщиков.

## Миграция из ModelLink 0.2.0

Нельзя переименовать этот пакет в «готовую версию 0.4.0 для App Store». Это рабочий UX-клиент с собственным IndexedDB (`modellink-mobile-v04`) и форматом `.mlink` версии 1, который **не гарантированно совместим с экспортами 0.2.0**. Чтобы не потерять файлы:

1. Экспортируйте важные проекты из опубликованной версии 0.2.0.
2. Получите её репозиторий и внедрите новую оболочку как UI-слой с адаптером к существующим CAD-загрузчикам и хранилищу.
3. Выполните миграционные тесты на копиях проектов, не меняя производственные исходники.
4. Только после проверки переносите сайт или отправляйте сборку в TestFlight.

## Проверки

- `npm run check`: 9 проверок парсеров, форматов, версий и структуры пакета + проверка синтаксиса.
- Браузерный интерфейс в Playwright проверен с **тестовой заменой IndexedDB на память**, так как управляемый браузер не разрешает переходить на локальный HTTP-адрес: отображение шести функций в ширине 390 пикселей, создание проекта, импорт SVG, сохранение замечания, 3D OBJ, экспорт и повторный импорт `.mlink`.
- Ручная проверка на iPhone по сценарию из `docs/QA_IPHONE_RU.md`: импорт из «Файлов», «Открыть в ModelLink», Quick Look, Share Sheet, жесты.

## Безопасность и ограничения

- Файлы сохраняются локально в IndexedDB текущего браузера; удаление данных браузера может удалить проекты.
- Расширения сторонних CAD-систем не исполняются, только сохраняются как оригиналы.
- Основные форматы для локального просмотра не гарантируют точности заводской спецификации; измерения следует перепроверять в CAD-программе.
- У `.mlink` ограничение 200 МиБ; на мобильных устройствах упаковка сотен мегабайт расходует оперативную память.
- Отсутствуют серверные учётные записи, командная синхронизация, экспорт PDF-отчётов, высокоточные производственные размеры и полноценное сравнение геометрии версий.

## Состав проекта

- `index.html`, `styles.css`, `app.js`: полнофункциональный веб-интерфейс.
- `core/storage.js`: IndexedDB, проекты, файлы, версии, замечания.
- `core/geometry.js`: DXF/OBJ/STL/GLB базовые парсеры.
- `core/pack.js`: импорт/экспорт ZIP-пакета `.mlink`.
- `vendor/`: JSZip, `@capacitor/core` (ESM) и лицензии.
- `www/`: собранные статические ресурсы для Capacitor.
- `ios/`: Xcode-проект с нативным модулем.
- `tools/asc_setup.py`: подготовка App Store Connect для workflow.
- `tests/`: автоматические тесты Node.js.
- `scripts/`: сборка, одиночный HTML и локальный сервер.
