# Задание для Claude in Chrome: создать приложение ModelLink в App Store Connect

Сделай только это, больше ничего не меняй.

1. Открой https://appstoreconnect.apple.com/apps → кнопка «+» → **New App**.
2. Заполни:
   - Platforms: **iOS**
   - Name: **ModelLink** (если имя занято — «ModelLink: чертежи и 3D»)
   - Primary Language: **Russian**
   - Bundle ID: **com.neverlandplayworks.modellink** (выбери из списка, он уже зарегистрирован)
   - SKU: **modellink-ios**
   - User Access: **Full Access**
3. Нажми **Create**.

Не трогай другие приложения, сертификаты, цены и тексты. В конце сообщи, создано ли приложение и под каким именем.
