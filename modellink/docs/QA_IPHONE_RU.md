# QA: проверка сборки TestFlight на iPhone

Сценарии для ручной проверки на устройстве. Отмечайте результат и модель iPhone / версию iOS.

| Код | Сценарий | Ожидаемый результат |
|---|---|---|
| IOS-01 | Первый запуск | Главная с шестью действиями, демо-проект «План склада» |
| IOS-02 | «Открыть файл» → PDF из iCloud Drive | Файл в проекте «Мои файлы», кнопка «Открыть PDF» показывает все страницы в Quick Look |
| IOS-03 | Импорт DXF | Чертёж виден, перемещение одним пальцем, масштаб двумя, «Вписать» сбрасывает вид |
| IOS-04 | Измерение на DXF | Две точки → расстояние в единицах чертежа |
| IOS-05 | Измерение на изображении + калибровка | Пиксели → «Задать масштаб» → следующие измерения в мм/м |
| IOS-06 | STL / OBJ / GLB | Модель вращается одним пальцем, масштаб двумя |
| IOS-07 | USDZ | Кнопка «Открыть модель» → Quick Look с AR |
| IOS-08 | DWG (2000, 2007, 2013, 2018) | Чертёж открывается со слоями и цветами; «Слои», «Фон», измерение с привязкой; экспорт в DXF и PDF |
| IOS-08b | STEP / IFC | Карточка «Оригинал», «Отправить» открывает Share Sheet |
| IOS-09 | Тот же файл ещё раз | Версия 2, версия 1 доступна в «Версии файла» |
| IOS-10 | Замечание на чертеже | Метка на месте касания, статус «Готово»/«Вернуть» |
| IOS-11 | «Поделиться» в проекте | Share Sheet с файлом `.mlink`; «Сохранить в Файлы» записывает пакет |
| IOS-12 | Импорт `.mlink` из «Файлов» | Проект восстановлен со всеми версиями и замечаниями |
| IOS-13 | В «Файлах» / Mail: «Поделиться» → ModelLink | Приложение открывается, файл попадает в «Мои файлы» |
| IOS-14 | Двойной тап по `.mlink` в «Файлах» | Открывается ModelLink, проект импортирован |
| IOS-15 | Кириллица и пробелы в имени | Имя не искажено |
| IOS-16 | Отмена выбора файлов | Ничего не создаётся, сообщений об ошибке нет |
| IOS-17 | Файл больше 100 МБ | Понятное сообщение о лимите |
| IOS-18 | Удалить версию / проект / все данные | Подтверждение, затем данные удалены |
| IOS-19 | Тёмная тема, iPhone SE, крупный шрифт | Кнопки не перекрываются, вырез и панель жестов не закрывают контент |
| IOS-20 | Перезапуск и обновление сборки | Проекты на месте |
| SEC-01 | Проект → «Защищённая отправка» (ключ по QR) | Пакет отправлен, показан QR, пакет в «Отправленных» |
| SEC-02 | Второй телефон: открыть .mlink, «Сканировать QR» | Пакет открыт в песочнице, водяной знак с именем получателя |
| SEC-03 | Неверный пароль / ключ | «Неверный пароль» / «Неверный ключ доступа» |
| SEC-04 | Только просмотр | Нет экспорта, «Поделиться», Quick Look |
| SEC-05 | Одноразовый пакет: закрыть, открыть снова | «Одноразовый пакет уже был открыт» |
| SEC-06 | Срок истёк (дата вчера) | Пакет не открывается |
| SEC-07 | Снимок экрана в пакете | Предупреждение, запись в журнале |
| SEC-08 | Запись экрана из Пункта управления | Чертёж скрыт |
| SEC-09 | Перевернуть телефон экраном вниз / три пальца | Пакет закрыт, сейф заперт, главный экран |
| SEC-10 | «Ознакомлен» → квитанция → отправителю → импорт | «Подпись верна», имя и время в «Отправленных» |
| SEC-11 | Сейф: Face ID, «В сейф», свернуть приложение | Сейф заперт, проект не виден в списках |
| SEC-12 | «Скрыть» область штампа → защищённая отправка | Получатель видит обезличенную копию |
| SEC-13 | iPad: альбомная и книжная ориентация, Split View | Боковое меню, без обрезки |
