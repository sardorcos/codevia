# ModelLink: решение по дизайну 0.4.0

**Цель:** пользователь должен понять назначение и доступные действия при первом открытии, не посещая «Помощь».

## Что изменено

| Было в первоначальных макетах | Решение 0.4 |
|---|---|
| Несколько отдельных разделов под каждую задачу | Один главный экран с шестью действиями |
| Большие изображения проектов занимали значительную часть главной | Короткая строка проекта, больше свободного пространства |
| Пять и более инструментов постоянно поверх чертежа | Инструменты в компактной панели, навигация в просмотрщике скрыта |
| Настройки форматов вне основного сценария | Карточка «Форматы файлов» на главной |
| Сложный мастер создания проекта | Одна форма: название и необязательное описание |
| Непонятное обещание открыть «любой» файл | Разделены просмотр и передача оригинала |

## Первый экран при 390×844

Элементы первого экрана по порядку:

1. Логотип, обозначение локального режима.
2. Заголовок «Все чертежи. Один экран.»
3. Две основные кнопки: «Открыть файл» и «Проект».
4. Все шесть функций в сетке из двух колонок.
5. Последние проекты и ссылка на полный список (ниже основной области видимости).
6. Четыре вкладки навигации.

Проверено, что последний функциональный блок завершается выше нижней навигации на мобильном экране шириной 390 пикселей.

## Приоритет дальнейшего UX

- Минимум действий до просмотра исходника: целевой показатель 2 нажатия из главной.
- Экран ошибочного CAD-просмотра всегда предлагает безопасную отправку оригинала.
- Для 3D измерений обозначать источник и точность, не показывать ложные значения.
- Доступность: размер активных областей от 44 pt, озвучиваемые имена для кнопок и минимум декоративных элементов.
