# Changelog

## 1.2.0

Переработка интерфейса по самокритике вёрстки и дизайна.

### Новое
- **Светлая тема.** «Настройки → Оформление»: «Авто» (как в iOS), тёмное или светлое. Редактор кода, консоли, инспектор, JSON и строка состояния iOS переключаются вместе с интерфейсом.
- **iPad с открытым инструментом.** Список файлов уступает место, чтобы код и предпросмотр оставались удобной ширины. На вертикальном iPad рядом с панелью остаётся одна колонка: код, а для инспектора — предпросмотр.
- **Список инструментов по группам** («Учёба», «Веб», «Данные и API», «GitHub») с короткими описаниями. Три пункта GitHub объединены в один инструмент с разделами «Проект», «Клонировать» и «Аккаунт».

- **Вход через GitHub по коду.** Подключён GitHub App «Codevia Pocket»: кнопка «Войти через GitHub» работает без токенов. После входа приложение предлагает выбрать репозитории, к которым Codevia получит доступ; в списке репозиториев есть кнопка «Не видите репозиторий? Дайте доступ».

### Улучшено
- **Редактор:** строка с путём и строка состояния убраны, «Сохранено» и кнопки перенесены в строку вкладок. На iPhone SE под код стало больше места. На телефонах перенос длинных строк включён по умолчанию (для новых установок).
- **Панель клавиш:** эмодзи и символы заменены иконками в едином стиле. Кнопка Emmet показывается только для HTML, CSS и PHP.
- **HTTP-клиент и JSON:** одна главная кнопка, редкие действия (cURL, fetch(), сжатие, сортировка ключей) — в меню «…». Вкладки запроса — в одну прокручиваемую строку.
- **Шапка:** понятная иконка «Инструменты» (гаечный ключ), на iPad и Mac — с подписями.
- **Файлы:** фильтры отделены от действий, короткая подсказка поиска. «Проверка файлов» — в меню проекта.
- **Новый проект:** у каждого шаблона своя иконка, готовые проекты — на отдельной вкладке.
- **Приветствие** рассказывает обо всех возможностях: JavaScript/TypeScript, GitHub, инструменты, уроки.
- **Настройки:** у выбора языка видна подпись, длинные названия переносятся, а не обрезаются.
- Мелочи: убран дублирующий блок «Продолжить» на главном экране, компактная плашка «Без интернета» в предпросмотре, пустая консоль без лишней кнопки, стрелка у поля ввода для `input()`.

### Внутри
- Единая шкала размеров шрифта и скруглений (CSS-переменные `--fs-*`, `--radius-*`), цвета интерфейса и подсветки кода — только через переменные темы.

## 1.1.0

Ответ на аудит 3 (`docs/AUDIT-3.md`) и большой набор новых возможностей.

### Новое
- **GitHub:** вход по коду (Device Flow, GitHub App) или токеном, токен хранится в Связке ключей. Клонирование, изменения с diff, коммит и пуш, pull с разрешением конфликтов, создание репозитория, публикация на GitHub Pages, значок ветки в шапке проекта.
- **JavaScript и TypeScript:** новый тип проекта. Импорты между файлами, JSON, `console.table`, таймеры, `prompt()`, `fs`/`path` по файлам проекта, точные номера строк в ошибках.
- **Пакеты Python:**
  - встроены и работают офлайн numpy, pandas, matplotlib, scipy, scikit-learn, sympy, pillow, bs4, regex, pyyaml, networkx;
  - остальные 329 пакетов Pyodide загружаются при первом `import` и кэшируются;
  - `requirements.txt` ставит пакеты из PyPI;
  - графики matplotlib и `Image.show()` выводятся в консоль.
- **Редактор:** Emmet (`div.card>h2+p`), сниппеты, форматирование Prettier (в том числе при ⌘S), подсветка ошибок со счётчиком, переход к определению, символы файла, поиск всех использований, образцы цветов с палитрой.
- **Инструменты:** HTTP-клиент, просмотр и форматирование JSON, пипетка и конвертер цветов (HEX/RGB/HSL/HSV, контраст WCAG), предпросмотр Markdown, офлайн-библиотеки одной кнопкой (Tailwind, Bootstrap, Vue, Alpine, htmx, Chart.js, lodash, dayjs, animate.css).
- **Инспектор предпросмотра:** дерево DOM, стили с источником в файле, блочная модель, журнал сетевых запросов, выбор элемента касанием.
- **iPad и Mac:** файлы, код и предпросмотр (или запуск) рядом, предпросмотр обновляется при наборе, сочетания ⌘1–⌘4, ⌘⇧F, ⌘K, поддержка указателя.
- **Файлы:** множественный выбор, перемещение и удаление одним действием, операции с папками, история отдельного файла со сравнением и восстановлением.
- **Предпросмотр:** `XMLHttpRequest` (`$.getJSON`, axios), формы GET/POST (`$_POST` в PHP), переходы через `location.href`, скрипты TypeScript/JSX, Markdown-страницы.
- **Интерактивный ввод:** `input()` в Python и `prompt()` в JS спрашивают прямо в консоли, программа продолжает работу с ответом.
- **Уроки:** три мини-курса (HTML/CSS, JavaScript, Python) по 5 уроков с заданием, подсказкой и автоматической проверкой.
- **Готовые проекты:** 8 стартовых проектов в «Новый проект» (Tailwind, Vue, Alpine, Chart.js, Bootstrap, pandas, PHP-форма, JS-игра). Работают без интернета.
- **GitHub: ветки и Pull Request:** создание ветки от текущей версии и Pull Request в основную ветку прямо с телефона.
- **14 языков интерфейса:** английский, русский, испанский, немецкий, французский, итальянский, португальский (Бразилия), турецкий, украинский, узбекский, казахский, китайский (упрощённый), японский, корейский. Язык выбирается в настройках.

### Исправлено (аудит 3)
- Собственную резервную копию больше 60 МБ нельзя было импортировать (R1).
- Восстановление версии падало, если одинаковые байты хранились как текст и как двоичный файл (R2).
- Python запускал старую версию изменённых модулей проекта, а память воркера росла с каждым запуском (R3, R6).
- Имена с `#` или зарезервированными словами ломали экспорт и резервную копию (R4).
- Серия удалений вытесняла автоверсии: теперь версии моложе 24 часов не удаляются (R5).
- Сборка мусора выполнялась при каждом сохранении версии (R7), автосохранение перекодировало весь проект (R8).
- Быстрый вывод программы замораживал интерфейс (R9), картинки в предпросмотре кодировались повторно (R10).
- Экспорт большой резервной копии требовал сотни мегабайт памяти (R11).
- Поиск по файлам тормозил на каждом нажатии клавиши (R14); переименование проекта читало все его файлы (R15).
- На iPad панель запуска не обновлялась после завершения программы.
- Предупреждения библиотек при выводе графиков попадали в консоль пользователя.
- В предпросмотре не работали формы, которые обрабатывает JavaScript (Vue, React, `addEventListener('submit')`).

## 1.0.0 — первая версия для TestFlight

Полная переработка прототипа UI 0.3 в продакшн-приложение (результаты аудита — в `docs/AUDIT.md` и `docs/AUDIT-2.md`).

### Новое
- Нативное iOS-приложение (Capacitor 8): проекты в «Файлах», системное меню «Поделиться», тактильный отклик, безопасные зоны.
- Python 3 (Pyodide) и PHP 8.3 на устройстве: ввод для `input()`, `$_GET`, кнопка «Стоп», понятные трейсбеки.
- Редактор CodeMirror 6: автодополнение, поиск и замена, отмена, история изменений для каждого файла.
- Предпросмотр: страницы, картинки, шрифты, `fetch()`, модули, консоль, полноэкранный режим.
- Поиск по коду всего проекта, проверка проекта с переходом к строке.
- История версий с дедупликацией; автоматические версии перед удалением и восстановлением.
- Резервная копия всех проектов; журнал ошибок на устройстве.
- Приветственный экран, политика конфиденциальности, лицензии.

### Исправлено (из аудита 0.3)
- Ловушка полноэкранного предпросмотра; `</script>` в JS ломал предпросмотр; пути `../` не работали.
- Тихая потеря данных при нехватке места; запись всего состояния на каждое нажатие клавиши.
- ZIP-бомбы, мусор macOS, кириллица CP866, дубликаты имён.
- Цели нажатия меньше 44 pt, зум iOS при фокусе, шапка под Dynamic Island, пустая иконка `</>`, недоступные строки и диалоги, низкий контраст.

### Удалено
- Экран «Серверы» (SFTP/FTP). В 1.0 нет реального подключения, поэтому нет и экрана-заглушки (App Store 2.1). Вернётся вместе с нативным SSH-модулем.
