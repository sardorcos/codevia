# Changelog

## UI 0.3.0 — 21.11.2026

### Дизайн
- Уплотнены header, project rows и навигация.
- Унифицированы три варианта кнопок, иконки, отступы и состояния.
- Убраны декоративные дубляжи: герой-вступление, лишние нижние разделы, отдельная кнопка предпросмотра внутри редактора.
- Добавлена переключаемая плотность интерфейса и размер шрифта кода.
- Редактор: подсветка, горизонтальная прокрутка и переключаемый перенос строк.
- Превью: максимальная рабочая область, sandbox, CSP.

### Рабочие функции дизайн-ветки
- Локальное хранилище IndexedDB, файловое дерево, история контрольных точек.
- ZIP STORE/Deflate import, ZIP STORE export, CRC32, лимиты, проверка имён.
- Проверка локальных ссылок и JSON.
- Локальные профили серверов **без паролей**, реального соединения нет.

### Отложено для интеграции
- Перенос вида экранов в React-код Codevia 0.2 с сохранением CodeMirror, Pyodide, PHP.wasm и Codevia Bridge.
- Тесты на iOS, нативная сборка, распространение через TestFlight.
- Прямое обновление закрытой опубликованной версии (доступ к репозиторию в этом сеансе отсутствовал).
